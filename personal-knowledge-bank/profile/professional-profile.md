# Professional Profile

## Role
A back-end developer working in an online-banking context. Designs and
builds server-side services and REST APIs in C# on ASP.NET Core that power
customer-facing banking applications.

## Expertise
Main areas of expertise:
- C# and .NET (ASP.NET Core) backend development
- Designing and building REST APIs and microservices
- Data access and persistence (Entity Framework Core, SQL Server)
- Authentication, authorization and API security (OAuth 2.0, OpenID Connect, JWT)
- Automated testing (xUnit, integration tests) and CI/CD pipelines

## Current goals
At the moment, the focus is on:
- designing clean, well-documented and versioned REST APIs
- improving service reliability, observability and performance
- strengthening security and compliance across backend services
- using MCP to speed up development and documentation workflows

## How an AI assistant can help
An AI assistant can help with:
- summarising refinement and architecture-review meetings
- drafting API documentation and usage examples
- scaffolding unit and integration tests
- reviewing C#/.NET code for performance, security and best practices
- organising learning notes
